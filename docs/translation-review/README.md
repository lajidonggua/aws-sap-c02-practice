## 原文的边界

英文题干和选项按原始内容保留，供学习者展开核对。能从上下文唯一识别的 OCR 缺字在中文恢复；无法确定的缺失不补造。例如 Q32 缺少所引用的 SCP 内容，Q153E 缺少路径模式，Q483 缺少 A 选项且 B 的 ROS 疑为 RDS。这些限制在题目或已有解析中说明。

错误干扰项仍然忠实翻译其原有方案，不在翻译中偷偷改成可行架构。本轮不更改此前校准的答案、歧义结论或学习记录。关于参考答案的证据见[答案校验记录](../answer-audit/README.md)。

## 英文原选项

主刷题、原版题库、多选专练和模拟考均在每个选项下提供独立的“查看 X 的英文原选项”。答题前后都可查看；鼠标和键盘展开不会选择或提交答案。闪记和直接背题中也保留英文核对入口。

## 维护与验证

修改记录后运行 `node scripts/build_translation_review.cjs`，再运行 `node build_quick_cards.cjs`，同步题库、解析中的题目条件和速记卡。若重新生成答案审校数据，应在其后重新执行翻译整合，避免旧的单项中文修复覆盖本轮校验。

`test_translation_review.cjs` 检查全部题号和中文覆盖、乱码标记、策略代码以及来源完整性哈希；英文原文、选项字母与审定答案必须与校验前版本一致。`test_english_options.cjs` 检查所有英文入口及安全转义。另有真实浏览器检查展开、作答、复盘、移动端和桌面显示，以及原有进度与练习集合回归检查。
