把方法用在每一道题上

记住判断依据，比记住选项更有用。

记忆：一职责、一对比、一变式

  1. 一句话说职责：“SQS 让任务排队，消费者自己取。”
  2. 比较一个近邻：“SNS 把通知分发给订阅者，两者可以组合。”
  3. 改变一个条件：“现在要求多组系统分别处理同一消息，设计要怎样改？”

关掉提示再说出来。说不清的地方，就是下次要补的点。

刷题：问什么 → 限什么 → 比什么

  1. 先看问法：要求低成本、少运维，还是最短恢复时间？
  2. 圈出硬约束：协议、网络、停机时间、数据一致性、权限和选几项。
  3. 逐项排除：技术可行还不够，要符合全部约束，再比较取舍。
  4. 补一句理由：“因为 __，所以选 __；另一个方案违背 __。”
错题怎样复盘？只记一句原因

把错因分成：名词不懂 / 漏看条件 / 混淆服务边界 / 多选漏项。再用一句话修正，例如：“把高可用当成读扩展了；传统 RDS Multi-AZ 备用实例不承担读请求。”

当天重看解释；隔天遮住答案再做。优先解释为什么其他选项不合适，题目次序变化后仍能判断，才说明理解在迁移。

去复盘错题 →
考前时间很少，怎样安排？
  1. 碎片时间：先处理到期卡与错因，补最弱的 1 个点；不要临考一口气背大量新服务。
  2. 从专题到混合：先少量相关题验证概念，再混合做题，避免靠连续题的主题猜答案。
  3. 留一次完整练习：安排 75 题、180 分钟的模拟，再单独留复盘时间，检查阅读速度、多选完整性和后半程注意力。
  4. 收尾：复述易混服务的适用条件；检查正式考试安排，保证休息。

本站正确率不能换算成官方分数；这条路线帮助建立基础，不能替代完整考纲、实操与陌生题检验。

进入模拟练习 →
复习提醒怎样安排？

完成本节后，默认明天巩固。已能解释的内容，可展开“调整复习间隔”，选择按间隔复习；连续选择后依次安排在 1、3、7、14 天后。随时都可以提前复习。

这些间隔是便于执行的默认值，并非适合所有人的最佳间隔。学习研究支持主动检索和分散练习；完成记录表示走过一轮学习；复习间隔由你的选择决定，不按小测对错推断掌握程度。

提醒显示在网站内；没有邮件或手机推送。
